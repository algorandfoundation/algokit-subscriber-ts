## Installation

Version 3 of AlgoKit Subscriber targets `algosdk@3` and `@algorandfoundation/algokit-utils@9`, both of which are peer
dependencies you install alongside it:

<Tabs>
  <TabItem label="npm">
    ```bash
    npm install algosdk@^3.0.0 @algorandfoundation/algokit-utils@^9.0.0 @algorandfoundation/algokit-subscriber
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add algosdk@^3.0.0 @algorandfoundation/algokit-utils@^9.0.0 @algorandfoundation/algokit-subscriber
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add algosdk@^3.0.0 @algorandfoundation/algokit-utils@^9.0.0 @algorandfoundation/algokit-subscriber
    ```
  </TabItem>
</Tabs>

If you need to target `algosdk@2`, use version 2 of the subscriber instead:
`npm install algosdk@^2.10.0 @algorandfoundation/algokit-utils@^7.1.0 @algorandfoundation/algokit-subscriber@^2.2.0`.

## Quick Example

```typescript
import { AlgorandClient } from '@algorandfoundation/algokit-utils'
import { AlgorandSubscriber } from '@algorandfoundation/algokit-subscriber'
import { TransactionType } from 'algosdk'

const algorand = AlgorandClient.testNet()

const subscriber = new AlgorandSubscriber(
  {
    filters: [
      {
        name: 'filter1',
        filter: {
          type: TransactionType.pay,
          sender: 'ABC...',
        },
      },
    ],
    maxRoundsToSync: 100,
    syncBehaviour: 'skip-sync-newest',
    watermarkPersistence: {
      get: async () => 0n,
      set: async (watermark) => { /* save watermark */ },
    },
  },
  algorand.client.algod,
  algorand.client.indexer,
)

// Set up subscription(s)
subscriber.on('filter1', async (transaction) => {
  // ...
})

// Set up error handling
subscriber.onError((e) => {
  // ...
})

// Either: Start the subscriber (if in long-running process)
subscriber.start()

// OR: Poll the subscriber (if in cron job / periodic lambda)
subscriber.pollOnce()
```
